# Enchanter/Bladebinder

Generated from `game/data/recipes.json` by `scripts/dev/Write-SystemLists.js`. 13 recipes, 13 of them reach the server. A row the server is not asked about is tempering: the armour table and the grindstone never call the server.

By rank: novice 3, advanced 6, expert 4, master 0.

The rank on the row is the rank. It is the rank of the staff's spell in the college book, not the dearest ingredient: every staff asks for heart stone, which is master mining, so a Bladebinder below master buys it. An item has no gold price.
