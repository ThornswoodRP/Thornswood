# Harnesses that stay off the pull request gate, one a line, in name order:
#   name  reason
# The gate (build.yml, "Run the gate harnesses") runs every test-*.js and
# test-*.ps1 in tests\ and in a product's tests folder not named here, as
# scripts\dev\Gate-Harnesses.ps1 lists them (#3009). One in tests\ is named by
# its file name, one beside its product by its path, launcher/tests/test-x.ps1,
# which sorts by its first letter among the rest. A new harness is on the gate
# without touching any shared line. To take one off, add its line here in name
# order; to put one on, take its line out. Gate-Harnesses.ps1 stops the build on
# a line with no reason, a name that is no harness, a name twice, or lines out
# of name order.
# Every harness still runs in the nightly.
#
# "own step in build.yml" is a harness build.yml runs in a step of its own,
# so the gate does not run it a second time. tests\test-2513-every-harness-listed.ps1
# holds those lines to what build.yml runs.
#
# "fails on main" is a harness that is red on main, with the issue that puts
# it right; the line goes when it passes again. Gate-Harnesses.ps1 stops the
# build on one that names no issue.
#
# No harness is off the gate for want of sorting. Until 27 Nov 2026, 277 lines
# here said "not sorted yet": off the gate since #2513 on 21 Oct, when the
# gate ran every harness on one runner and they cost minutes. They ran only in
# the nightly, which never once passed, so 16 of them went red one by one
# (a harness of a fix from 23 Sep among them) and nothing said so on any pull
# request. Since #5183 a pull request runs only the harnesses its change can
# reach, in shares, so a harness on the gate costs a pull request nothing
# unless the change can break it (#7100). Gate-Harnesses.ps1 stops the build
# on a "not sorted yet" line.
